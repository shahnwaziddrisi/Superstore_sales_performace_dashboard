
Project Title: Superstore Sales Performance Dashboard

Description:
This dashboard provides a comprehensive overview of sales performance for a retail superstore. Built using Power BI, it highlights key business metrics including Total Customers, Total Sales, Profit, and Items Sold. The dashboard allows dynamic filtering by product Category and Region, enabling targeted analysis.

Key insights include:

Top-selling sub-categories such as Phones and Chairs.

Segment-wise sales distribution showing Consumer as the leading segment.

Year-over-year sales trend with a 3-month forward prediction.

Top 5 profitable products identified to guide future marketing and inventory decisions.

The dashboard demonstrates strong data storytelling and actionable insights, helping business stakeholders make informed decisions quickly and effectively.
